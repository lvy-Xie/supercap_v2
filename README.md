# Supercap V2 超级电容控制器

面向 RoboMaster 应用的超级电容控制器项目，使用 TI C2000 主控和 GaN 功率器件，围绕双向四开关 Buck-Boost 功率级进行开发。

本说明根据提供的原理图 PDF 和 `Supercap_V2` 工程源码整理。当前先建立硬件与软件目录，归档平均电流控制工程；具体电气参数、控制参数、性能指标与实测结果后续完善。

## 项目组成

### 硬件概览

提供的原理图涵盖以下模块，仅在此概述其功能：

- **功率级**：由两个半桥与功率电感构成四开关 Buck-Boost 电路，配有 GaN 栅极驱动、输入与电容侧滤波及辅助供电。
- **主控与调试**：C2000 主控负责采样、控制和外设调度，预留程序下载、调试与通信接口。
- **采样电路**：包含电流采样、电压采样和温度采样电路，为控制与状态观测提供信号。
- **外部接口**：包含输入、电容、底盘及 CAN 接口。
- **显示与辅助功能**：包含指示灯、蜂鸣器与风扇接口。

原理图中存在某个模块或接口，并不代表当前软件已启用该功能。元件参数、引脚对照、设计版本对应关系与硬件文件后续补充。

### 平均电流控制软件

当前导入的工程以经采样换算的电容电流作为闭环反馈，结合电流调节与电压限制生成两桥 PWM；另有输入功率控制路径。它不属于已完成的逐周期峰值电流控制实现，因此归档到 `software/平均电流/`。

工程将周期性采样换算和控制运算放在 CLA 中，CPU 负责初始化、采样数据提交、启停监督、后台校准及遥测等工作。

| 路径 | 内容 |
| --- | --- |
| `main.c` | 系统入口与初始化流程 |
| `Codes/supercap.c` | 启停监督与后台服务 |
| `Codes/control.c` | 控制共享变量与初始化 |
| `Codes/includes/control_cla.h` | 平均电流控制、功率控制和 PWM 分配 |
| `Codes/cla_tasks.cla` | CLA 任务与周期性控制计算 |
| `Codes/cla_adc.c` | ADC、DMA 与 CLA 数据链路 |
| `Codes/telemetry.c` | 串口遥测 |
| `Codes/buzzer.c` | 蜂鸣器驱动 |
| `c2000.syscfg` | 外设静态配置来源 |
| `device/`、`targetConfigs/` | 器件支持与调试目标配置 |
| `docs/` | 原工程的调试说明 |
| `tests/` | 主机检查与测试 |
| `tools/` | 构建与采样校准工具 |

## 获取与构建

1. 下载仓库，在 Code Composer Studio 中导入 `software/平均电流/` 工程。
2. 准备 TI C2000 工具链、C2000Ware 与 SysConfig，并根据本机安装位置配置依赖。
3. 如使用配套脚本，进入工程目录后执行：

   ```sh
   cd software/平均电流
   sh tools/build.sh
   ```

构建脚本支持通过 `CCS_ROOT` 与 `C2000WARE_ROOT` 指定安装路径。原工程测试文件按原样归档；部分检查依赖本次未收录的音频处理工具，测试入口尚未针对本仓库裁剪。
